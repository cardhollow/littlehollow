SOS RULES
Players take turns placing S or O into empty cells.

Make S-O-S horizontally, vertically, or diagonally to score 1 point for every new SOS created.

If a player creates one or more SOS, that player keeps the turn and may place another letter.

The turn only changes when a move creates no SOS.

The game ends only when the board is completely full.
ABOUT SOS
SOS is a grid strategy game based on creating the sequence S-O-S.

Horizontal, vertical, and diagonal sequences all count.
SCORING
Each newly created SOS is worth 1 point.

A single move can create multiple SOS patterns.

Letters may participate in multiple different SOS patterns.
TURN RULE
A move that creates no SOS passes the turn.

A move that creates at least one SOS does not pass the turn.

This means one player can make several consecutive moves.
AI
EASY makes mostly random moves.

NORMAL prioritizes moves that create SOS.

HARD prioritizes scoring and also considers dangerous moves that allow the opponent to score.
