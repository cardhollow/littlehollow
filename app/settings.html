LIVE PROCESSING
Live mode reacts to meaningful application-state changes. It does not continuously submit the same state in a tight loop.
Examples of useful state: active application, open windows, current file path, selected file, and recent important events. Little Hollow does not automatically send the entire DOM or page contents.
